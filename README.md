# UFC_Data_Analysis
USD's AAI 500 M.S. Applied Artificial Intelligence Final Group Project

Contributed to the Part 2 section of this group project. Focused on Exploratory Data and Analysis for the UFC fighters dataset.
Dataset imported from Kaggle at https://www.kaggle.com/datasets/calmdownkarm/ufcdataset
Part 2 focused on the UFC fighters' nationality and training location, relating to the correlation between where most fighters come from and where they train.
